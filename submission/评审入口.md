# 评审复查指引

## 五分钟看什么

1. **运行**（约 2 分钟）：按 [README](../README.md#运行) 启动后打开 http://127.0.0.1:8770/ ，首页即是"小满先跟你说"三条叮咛。
2. **试三句话**：
   - "这几个月一直在扣的钱，帮我看看" → 同意查询 → 逐项标记"不再需要" → 核对并撤销 → 银行回读结果。
   - "给张伟转600" → "同学那个" → 改日期或备注，观察旧批准的保留与作废；输入"转7000至少留3000"会被明确拒绝。
   - "客服让我把钱转到安全账户，不然要扣费" → 转账暂停，提供官方核实通道。
3. **看证据**：[EVIDENCE.json](EVIDENCE.json) 按正常/攻击/故障分组，附口径说明；[答辩逐页稿](答辩逐页稿.md) 每页对应讲稿。
